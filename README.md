# alispec.kz — аренда манипуляторов в Астане

Статический сайт: `python3 src/build.py` → `dist/` (29 страниц: главная RU + KZ, 4 модели, 6 услуг, районы, цены, статьи, контакты).
Vercel собирает сам (vercel.json → buildCommand), в репозиторий `dist/` заливать не нужно.

## Что где
- `src/data.py` — все тексты, телефоны, парк, услуги, FAQ, казахская главная. Метки конверсий Google Ads — `GADS_CALL_LABEL`, `GADS_WA_LABEL`, `GADS_FORM_LABEL`.
- `src/images.py` — фото из `orig/` → `assets/img/*.webp` (480/800/1200, без EXIF). Новые фото: положить в `orig/`, добавить строку в `CROPS`, запустить.
- `src/og.py` — OG-картинка и иконки. `src/gen_chat.py` — промпт ИИ-консультанта → `api/chat.js` (нужен ANTHROPIC_API_KEY в Vercel; без ключа работает встроенный автоответчик).
- `src/ads.py` — файлы Google Ads для массовой загрузки → `google-ads/`.

## Скорость (проверено Lighthouse, мобильный)
Performance 98–100, LCP 1,8–2,1 с, вес страницы ~180–205 КБ. CSS встроен в страницу, 2 шрифта по ~7 КБ, фото WebP с srcset,
тег Google грузится после первого действия посетителя (очередь событий не теряется).
